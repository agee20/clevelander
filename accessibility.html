Digital Accessibility Policy

Web Accessibility Statement

Our Commitment to Accessibility

The Clevelander Bar & Grill is committed to facilitating the accessibility and usability of its website, www.clevelanderbar.com, for all guests, including individuals with disabilities. We continually work to improve user experience for everyone and apply the relevant digital accessibility standards.

Accessibility Standards & Conformance

To accomplish this, our redesigned website implements the guidelines established by the World Wide Web Consortium (W3C) Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA. These guidelines define best practices for making digital web content accessible to a wider range of people with disabilities, including:

  • Semantic HTML5 Structure: Clear landmark roles, logical heading hierarchies (H1 through H4), and descriptive page titles to assist screen reader navigation.
  • Full Keyboard Operability: All navigation menus, tab controls, modal dialogues, and links can be navigated using only a keyboard.
  • High Color Contrast: Text and UI elements comply with WCAG 2.2 AA contrast ratios (minimum 4.5:1 for body copy).
  • Accessible Menus: Menus are coded as live text rather than flat raster images, allowing screen magnification, screen reading, and custom text styles.
  • Skip to Content Landmark: A visible, accessible bypass link allows keyboard users to jump directly to main page content.
  • Reduced Motion Support: CSS queries respect user system preferences for reduced motion and animations.
